### 주요 기능

- 행성(챌린지) 생성 및 행성 커스텀
- 챌린지 참여도로 랭킹 산정
- 인증 사진 업로드 및 AI로 유사도 검증
- 카테고리별 사용자 통계 분석
- 매주 인기 키워드 분석
